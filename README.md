# Group-Project-2-CLI-Coding-Assistant
Forge is a command line AI coding assistant. You give it a task in plain English, and it reads and edits files, searches the web or our docs, and keeps going until the task is done.

It connects to three MCP servers:

Filesystem server for reading and editing local files
Tavily for web search
Custom RAG server that answers questions from the LangChain docs using Corrective RAG (CRAG)

It works with local models through Ollama and cloud models through Groq.
